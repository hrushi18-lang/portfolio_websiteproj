# Hrushi's Portfolio

Hi, I'm Hrushi! I'm a first-year student currently studying AI & Business at Scaler School of Technology, along with pursuing a B.S. in Computer Science from BITS Pilani.

This repository contains the source code for my personal portfolio website, built with simple, semantic HTML and CSS. I wanted to create something that reflects who I am right now: a student who is constantly learning, building, making mistakes, and exploring.

## About the Project

I built this portfolio entirely from scratch without using any external libraries, frameworks, or even images. The design is heavily inspired by brutalist and minimalist aesthetics—focusing strictly on typography, layout, and raw CSS styling to communicate ideas clearly and boldly. 

### Why No Images?
I wanted to challenge myself to rely solely on the power of typography (using fonts like *Syne*, *Space Grotesk*, and *Space Mono*), CSS Grid, and Flexbox to make the design engaging. It’s an exercise in keeping things simple while still making an impact.
